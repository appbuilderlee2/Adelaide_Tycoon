# Adelaide Tycoon V0.4

A local multiplayer, pass-and-play PWA board game designed for one phone and 2–6 players.

## V0.4 highlights

- Pass-the-phone privacy screen between turns
- Animated two-dice presentation and optional faster movement mode
- Chance / Community Chest full-screen card reveal
- Browser-generated sound effects with no external audio files
- Optional vibration feedback on supported devices
- Settings for sound, vibration, privacy and animation speed
- V0.3 gameplay retained: property groups, building, rent, jail, mortgage, auctions, trading, bankruptcy and winner flow
- V0.3 local saves migrate automatically to V0.4

## Run

Open `index.html`, or publish the repository with GitHub Pages.
