# Adelaide Tycoon V0.5

A local multiplayer, pass-and-play PWA board game designed for one phone and 2–6 players.

## V0.5 highlights

- Fixed dice input with a new resilient dice handler
- New large dice control area designed for touch screens
- PWA cache strategy changed so installed iPhone apps receive the latest JS instead of staying on an older cached build
- New Adelaide board illustration in the centre of the board
- Stronger dice, pawn, event-card and turn transition animations
- New dark game header and refreshed visual hierarchy
- Version history shown inside Settings
- V0.4 gameplay retained: privacy hand-off, sound, vibration, event-card reveal
- V0.3 gameplay retained: property groups, building, mortgage, auctions and trading
- Existing local saves remain compatible

## Version history

- **V0.5** — dice fix, refreshed UI, illustrated board, animation upgrade, PWA cache fix
- **V0.4** — dice/card animations, sound, vibration, pass-the-phone privacy screen
- **V0.3** — colour groups, building rules, mortgage, auctions, upgraded trading
- **V0.2** — jail, event cards, bankruptcy and winner flow
- **V0.1** — basic dice, movement, buying property and rent
