# Adelaide Tycoon V1.2

A local multiplayer, pass-and-play PWA board game designed for one phone and 2–6 players.

## V1.2 Classic Rules Upgrade

- Doubles grant another roll after the current landing is resolved.
- Three consecutive doubles send the player directly to Jail.
- Adds a real **Go To Jail** square to the 25-space Adelaide board.
- Jail keeps the existing doubles-to-leave / third-attempt $50 flow.
- If a player declines an unowned property, the turn cannot end until the property is auctioned.
- Building stays even across a colour group.
- Four houses can be upgraded to a hotel only after every property in the colour group has four houses.
- Hotels have a stronger rent multiplier and a dedicated hotel visual.
- Bankruptcy caused by rent transfers the bankrupt player's properties to the creditor instead of deleting them.
- Bank bankruptcy returns properties to the bank.
- Retains the V1.1 one-screen layout, V1.0 mobile-game controls, V0.9 animation layer, V0.8 turn experience, Quick Mode and House Rules.
- PWA cache updated to `adelaide-tycoon-v12`.
